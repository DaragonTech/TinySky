# TinySky

A tiny procedural night sky for your terminal.

Because apparently even the night sky can fit in 50 lines of Python.

TinySky generates a new ASCII star field every time it runs. No dependencies, no framework, no build system, no account, no API key. Just Python.

## Run

```bash id="x9pz2a"
python tinysky.py
```

Requires Python 3 and approximately one command.

## Ideas

TinySky is intentionally tiny, which means there is plenty left to do.

- command-line options
- colored stars
- reproducible skies using seeds
- animated shooting stars
- constellation generation
- SVG or image export
- whatever else you can come up with

Fork it. Break it. Fix it. Add something unnecessarily complicated.

The source is short enough to read. All of it.
